## 한국어

### 프로젝트 소개

**건강Step**은 사용자의 운동수행능력을 측정하고, 그 결과를 바탕으로 보다 안전하고 효과적인 운동 강도를 추천하는 웹 기반 건강관리 애플리케이션입니다.

기존의 많은 운동 추천 서비스가 단순 설문 기반으로 운동 수준을 판단하는 것에 비해, 본 프로젝트는 사용자의 건강 상태와 실제 운동수행능력을 함께 고려하는 것을 목표로 개발되었습니다.

본 프로젝트는 고려대학교 캡스톤디자인 과제로 진행되었으며, 스포츠과학 지식과 웹 프로그래밍을 결합하여 제작되었습니다.

### 주요 기능

- **PAR-Q+ 설문 기반 건강 상태 확인**
  - 사용자가 운동을 시작하기 전, 자신의 건강 상태를 자가 점검할 수 있습니다.

- **StepTest4all 기반 유산소 능력 측정**
  - 스텝 테스트를 통해 심폐지구력과 관련된 VO2max를 추정하고, 결과에 따라 유산소 운동 강도를 추천합니다.

- **Brzycki 공식 기반 1RM 측정**
  - 반복 횟수와 사용 중량을 바탕으로 사용자의 1RM을 추정하고, 목표에 맞는 저항 운동 강도를 추천합니다.

- **운동 강도 추천**
  - 사용자의 측정 결과에 따라 보다 안전하고 효과적인 운동 방향을 제시합니다.

### 개발 배경

운동과 헬스에 대한 관심이 높아지면서 개인에게 맞는 운동 추천의 필요성이 커지고 있습니다. 그러나 단순 설문만으로는 사용자의 운동수행능력을 정확히 파악하기 어렵습니다.  
이에 따라 본 프로젝트는 건강 상태 확인, 유산소 능력 측정, 근력 수준 측정을 조합하여 더 신뢰도 높은 운동 추천 서비스를 구현하고자 했습니다.

## English

### Project Overview

**Health Step** is a web-based health management application designed to measure users’ exercise performance and recommend safer and more effective exercise intensity based on the results.

Unlike many existing exercise recommendation services that rely mainly on simple questionnaires, this project aims to combine health screening with physical performance assessment.

This project was developed as a capstone design project at Korea University, integrating sports science knowledge with web development.

### Key Features

- **Health Screening with PAR-Q+**
  - Users can self-check their health condition before starting physical activity.

- **Aerobic Fitness Assessment with StepTest4all**
  - The app estimates VO2max through a step test and recommends aerobic exercise intensity based on the result.

- **1RM Estimation with the Brzycki Formula**
  - The app estimates one-repetition maximum based on weight and repetitions, then recommends resistance training intensity according to the user’s goal.

- **Personalized Exercise Intensity Recommendation**
  - The app provides exercise intensity guidance based on the user’s measured fitness level.

### Background

As interest in fitness and health continues to grow, the need for more personalized exercise recommendations has also increased.  
However, simple questionnaire-based services often have limitations in accurately assessing physical performance.  
This project was created to provide safer and more effective exercise recommendations by combining health screening, aerobic fitness assessment, and strength estimation.

## 日本語

### プロジェクト概要

**健康Step**は、ユーザーの運動遂行能力を測定し、その結果に基づいて、より安全かつ効果的な運動強度を提案するWebベースの健康管理アプリケーションです。

既存の多くの運動推薦サービスが簡単なアンケート形式に依存しているのに対し、本プロジェクトでは、健康状態の確認と実際の運動遂行能力の測定を組み合わせることを目指しました。

本プロジェクトは、高麗大学のキャップストーンデザイン課題として制作され、スポーツ科学の知識とWeb開発を組み合わせて実装しました。

### 主な機能

- **PAR-Q+による健康状態チェック**
  - 運動を始める前に、ユーザー自身が健康状態を確認できます。

- **StepTest4allによる有酸素能力の測定**
  - ステップテストを通じてVO2maxを推定し、その結果に基づいて有酸素運動の強度を提案します。

- **Brzycki公式による1RM推定**
  - 使用重量と反復回数をもとに1RMを推定し、目的に応じたレジスタンストレーニングの強度を提案します。

- **運動強度の推薦**
  - 測定結果に基づき、ユーザーに適した運動強度の目安を提示します。

### 開発背景

健康やフィットネスへの関心が高まる中で、個人の状態に合った運動推薦の重要性が増しています。  
しかし、単純なアンケートだけでは、ユーザーの運動遂行能力を正確に把握することが難しい場合があります。  
そこで本プロジェクトでは、健康状態の確認、有酸素能力の測定、筋力レベルの推定を組み合わせ、より安全で効果的な運動推薦を行うことを目指しました。
